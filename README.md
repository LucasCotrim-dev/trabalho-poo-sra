### Instalação do JDK:
1. Acesse o site [Oracle JDK Downloads](https://www.oracle.com/br/java/technologies/downloads/).
2. Selecione o sistema operacional.
3. Para Windows, baixe o instalador x64 (.exe).
4. Execute o instalador e siga as instruções de instalação padrão.

### Instalação do Eclipse:
1. Visite o site [Eclipse](https://www.eclipse.org).
2. Acesse a seção de Downloads.
3. Baixe o instalador da IDE.
4. Após o download, execute o instalador.
5. Escolha "Eclipse IDE for Enterprise Java and Web Developers".
6. Conclua a instalação seguindo as instruções padrão.

### Instalação do Apache Tomcat Server:
1. Vá para [Apache Tomcat Downloads](https://tomcat.apache.org/download-90.cgi).
2. Sob as opções do core, escolha "64-bit Windows zip (pgp, sha512)".
3. Extraia o arquivo zip e adicione a pasta ao disco local.
4. No Eclipse, vá para a seção de servidores. Se não aparecer, pressione Ctrl + 3 e digite "servers".
5. Adicione um novo servidor, selecione Apache e escolha a versão 9.0.
6. Escolha o diretório onde está a pasta do Tomcat no disco local.
7. Selecione o servidor no Eclipse e nas configurações de "Server Locations", escolha "Use Tomcat installation (takes control of Tomcat installation)".
8. Clique em "Save All" (ícone número 3) ou use Ctrl + Shift + S.

### Instalação do XAMPP:
1. Visite o site [XAMPP](http://www.apachefriends.org/pt_br/download.html).
2. Selecione a versão mais recente e baixe o instalador.
3. Execute o instalador e siga as instruções de instalação padrão.

### Importação do Projeto:
1. Extraia o arquivo zip do projeto.
2. No Eclipse, selecione "File" na barra de opções.
3. Clique em "Import".
4. Em "General", escolha "Existing Projects into Workspace".
5. Clique em "Browse..." e selecione a pasta do projeto.
6. Após a seleção, clique em "Finish".

### Importação do Banco de Dados no XAMPP:
1. Após todas as instalações e importações, crie um banco de dados com o nome "rotinify".
2. Com o banco de dados selecionado, vá para "Importar".
3. Selecione o arquivo .sql e importe.

### Inicialização do Sistema ROTINIFY:
1. Certifique-se de que o servidor do banco de dados esteja ligado.
2. Na webapp, inicialize o sistema a partir da homepage.
3. No Eclipse, clique no símbolo de start verde.
4. Selecione o servidor Tomcat.
5. Clique em "Next" para verificar se o servidor está ativo.
6. Clique em "Finish".
